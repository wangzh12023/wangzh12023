# Language behavior

The homepage and public CV default to English. A valid `?lang=en` or `?lang=zh` URL takes precedence over the visitor’s explicit language choice saved as `zihan-locale`; without either, the site uses English. Browser language is not used. Language controls synchronize the URL, preference, and document language (`en` / `zh-CN`).

- `src/i18n.ts`: typed `Locale`, locale resolution, preference storage, and the static English/Chinese dictionary. `t()` interpolates named values and falls back to English.
- `src/data-zh.ts`: Chinese copy for projects, detail dialogs, and the smaller project archive. Research titles, tags, and established technical terms retain their English forms. Project identifiers, assets, and URLs remain stable.
- `src/main.ts`: renders the chosen language and preserves the project filter, anchor, expanded sections, page position, and open project dialog when switching. The dialog also exposes a language control.
- `src/i18n.css`: compact language controls and Chinese font fallbacks.
- `public/cv.html`: standalone bilingual CV with a current-language return link; printing uses the selected language.
- `public/credits.html`: standalone bilingual design and credits page.

Homepage CV and credits links carry the current `lang` parameter. URL parameters and document anchors are retained during language changes. The current green (`main`) and violet (`theme/violet`) versions use the same language behavior; their colors are selected by branch, with no color picker. The older five-theme behavior belongs to the historical `archive/themes` branch.

Research copy keeps terms such as Masked Next-Token Prediction, token, continuous latent reasoning, pre-router, Jacobi latent block, soft mixing, and inference in English. People and institution names use verified official forms, including 屠可伟 / Kewei Tu, 许岚 / Lan Xu, and 上海科技大学 / ShanghaiTech University.

Use `npm run check` to verify dictionary keys and `npm run build` for the production build. Browser QA should cover both languages, narrow navigation, project filters, dialog switching, and CV print pagination.
