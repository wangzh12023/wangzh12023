# Archived language behavior

This document describes the older `archive/themes` snapshot, including its five-theme picker. Current green and violet versions are maintained on `main` and `theme/violet`; this archive is not kept in sync with current content.

The archived homepage and public CV default to English. A valid `?lang=en` or `?lang=zh` URL takes precedence over the visitor’s explicit language choice saved as `zihan-locale`; without either, the site uses English. Browser language is not used. Language controls synchronize the URL, preference, and document language (`en` / `zh-CN`).

- `src/i18n.ts`: typed `Locale`, locale resolution, preference storage, and the homepage’s static English/Chinese dictionary. `t()` interpolates named values and falls back to English.
- `src/data-zh.ts`: complete Chinese copy for research, projects, their detail dialogs, and the secondary project archive. Project identifiers, assets, and URLs remain stable.
- `src/main.ts`: renders the chosen language and preserves the project filter, theme, anchor, expanded sections, page position, and open project dialog when switching. An additional language control inside the modal keeps switching accessible while it is open.
- `src/i18n.css`: compact language controls and Chinese font fallbacks; theme and base layout rules stay in the existing stylesheet.
- `public/cv.html`: standalone bilingual CV, including its print interface and current-language return link. Printing uses the currently selected language.
- `public/credits.html`: standalone bilingual design and credits page.

Homepage CV and credits links carry the current `lang` parameter. Theme query parameters and document anchors are retained during language changes. User content and proper project names may retain standard English names in the Chinese version.

Validation: TypeScript and production build pass. The dictionaries have matching typed keys; project translations retain stable IDs and links. Visual verification of both languages, narrow navigation, project filters, modal switching, and CV print pagination belongs in the browser QA pass.
