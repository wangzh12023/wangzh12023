## Portrait treatment

`portrait-cutout.png` uses the existing supplied photograph’s RGB pixels unchanged. A foreground alpha mask was computed locally using Apple Vision’s `VNGenerateForegroundInstanceMaskRequest`; the PNG was composed by adding that alpha channel to the original RGB pixels, with no face generation, retouching, or recoloring. The untouched original `portrait.jpg` remains available in the source assets.

The displayed `portrait-repaired.png` extends the transparent canvas to 1320 × 1320 and restores only the cropped viewer-right green shirt shoulder using an AI-generated patch. The patch is limited to x > 910, y ≥ 1010, with a 40-pixel transition at the original edge. All pixels outside that lower-right region, including the face, hair, glasses, and neck, retain the original photograph. The patch was placed as an embedded smart object over the original in Photoshop and exported as transparent PNG; the editable PSD is kept in the local `review/portrait-repair/` directory outside the public site. CSS multiplies side and bottom alpha gradients to blend the shirt into any site background without a rectangular edge.

The full transparent character artwork is displayed beside the name in the header, hidden from assistive technology. Its separately masked crown is used only as the mask for a small CSS gold glint. The photographic portrait has no crown or thumb overlays. The earlier extracted thumb files are retained as source assets but are not rendered.
